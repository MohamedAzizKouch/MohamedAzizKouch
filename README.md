## 🚀 Featured projects

### 🤝 Brand–Influencer Recommendation System
*Internship project · bidirectional recommender*

A hybrid recommender that matches brands with influencers in both directions. It combines **collaborative filtering (BPR/ALS)** with a **gradient-boosting model for cold-start cases**, and is evaluated with a leak-free protocol (disjoint cold-start holdout, bootstrap significance test, popularity baseline). Served through a **FastAPI + Docker** API with a web interface.

`Python` · `BPR/ALS` · `Gradient Boosting` · `DuckDB` · `FastAPI` · `Docker`

### 🤖 Intelligent HR ETL Pipeline
*LLM-driven BI automation*

An 8-step ETL pipeline where a **local LLM (Llama3 via Ollama)** profiles data quality and generates cleaning plans as structured JSON, so sensitive HR data never leaves the machine. Includes a multi-dimensional evaluation framework (coverage, relevance, improvement) benchmarked against a rule-based baseline on 3 HR datasets, with a Streamlit interface.

`Python` · `Ollama / Llama3` · `Streamlit` · `Pandas` · `SciPy`

### ☁️ Cloud-Native Decision Pipeline
*GCP e-commerce BI*

An event-driven **serverless pipeline** (Cloud Functions, Pub/Sub, Apache Beam on Dataflow) that cleans multi-format records, with BigQuery SQL views feeding a **Looker Studio** executive dashboard.

`GCP` · `Apache Beam` · `BigQuery` · `Pub/Sub` · `Looker Studio`

### 😊 Emotion Detection from Tweets
*Deep learning for NLP*

Benchmark of **4 deep learning architectures** for emotion classification on 20,000 tweets. A fine-tuned **DistilBERT** reached **92.6% test accuracy** and is deployed as a REST API on Google Cloud Run.

`TensorFlow/Keras` · `DistilBERT` · `FastAPI` · `Docker` · `Cloud Run`

### 📈 BI Solution (Final Year Project, 2024)
*Sales and click analysis*

BI solution designed with **GIMSI and Kimball**: a star schema (1 fact table, 5 dimensions), **SSIS ETL pipelines** loading PostgreSQL and NoSQL (JSON) data into a SQL Server warehouse through a staging area, and a multi-page **Power BI** report tracking 6 KPIs.

`SSIS` · `SQL Server` · `PostgreSQL` · `Power BI`
